# Tasks: Upstream Tools in Place of Own Tooling Code

**Input**: Design documents from `specs/023-upstream-tooling/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md),
[research.md](research.md)

**Tests**: Each swap keeps its capability shown by an existing test or a new
one (FR-012); tests that only the removed code used go with it.

**Organization**: Main (Claude Code) owns the Spec Kit records,
`docs/architecture.md`, `AGENTS.md`, reviews each Codex worker's diff and
commits it. Codex workers (`gpt-6-luna`, max effort, through the terminal
path) implement. Daybreak Blue reviewers did the security reviews (R0). A
fresh Codex reviewer gives the develop merge review of the code; a fresh
reviewer from the other provider reviews the coordinator's records.

**Private data**: No task writes a student name or record into the
repository or into Orca or Linear messages. Tests use synthetic fixtures.

**Own code**: Each worker reports the scc own-code lines it removed and added.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: Which user story this task belongs to (US1 to US4)
