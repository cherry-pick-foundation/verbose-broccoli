# Feature Specification: Raw derivatives

**Feature Branch**: `feature/raw-derivatives`

**Created**: 2026-09-30

**Status**: Draft

**Linear issue**: CHE-59

**Input**: Linear issue CHE-59, "Remove AI-generated derivatives from the work
vault's raw layer and keep them out", and the brief with which the `develop`
session started this feature on 2026-09-30.

The user decided on 2026-09-30 that a vault's raw layer holds only original
sources: catalogs (EGP, EVP), reference grammars (CGEL, the Grammar in Use
books), school textbooks and their answer keys, original exam papers,
published word books, provider materials (아잉카, 이그잼포유/Exam4You) and
official documents, plus the user's own records such as the class timetable
and the EduOK web capture. Worksheets, dated or selected word lists, and
trimmed or marked-up copies were generated by AI from those sources. They are
not raw evidence and are not cited as sources. Earlier imports admitted 43
such derivatives into the work vault.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - The work vault's raw layer holds only originals (Priority: P1)

The user removes the 43 derivatives that CHE-59 lists from the work vault's
raw layer, once, as an approved exception to raw's create-only rule, and the
removal is recorded.

**Why this priority**: It is the user's decision and the core of the issue.

**Independent Test**: Compare the vault's bags with
[removals.md](removals.md) and read the vault's `wiki/log.md`.

**Acceptance Scenarios**:

1. **Given** the checked list of 43 bags, **When** the removal is done,
   **Then** none of them remains under `raw/`, every other bag is unchanged,
   and `raw_import.py verify` passes.
2. **Given** the removal, **When** the user reads `wiki/log.md`, **Then** one
   entry gives the date, the count, the user's decision and the categories,
   with no student names.

---

### User Story 2 - Pages cite originals only (Priority: P1)

A reader of the work vault's Wiki finds no citation or link to a removed
file. Where a page relied on a derivative, it cites the original the
derivative came from, or drops the citation when no original is in raw.

**Why this priority**: Pages citing missing bags or dead links fail the Wiki
check.

**Independent Test**: Run `wiki-consistency check --wiki work`.

**Acceptance Scenarios**:

1. **Given** the updated pages, **When** `check` runs, **Then** it reports
   no finding other than the open bug CHE-58's (106 "page rule phone", 2
   "page rule date" and 1 "page rule english" findings on pages this feature
   does not change).
2. **Given** `wiki/sources/local-materials.md`, **When** a reader follows
   its links, **Then** none points at the removed files or at the two trashed
   worksheet folders.

---

### User Story 3 - Derivatives are flagged before admission (Priority: P2)

An agent that surveys a location or builds a file list for the raw import
points out files that look like AI-made derivatives and asks the user
before listing them for admission.

**Why this priority**: It keeps the removal from being needed again.

**Independent Test**: Read the `wiki-raw-import` skill's steps 1 and 4, the
vault schema template, and the four vaults' `AGENTS.md`.

**Acceptance Scenarios**:

1. **Given** the skill's survey and file-list steps, **When** a location
   holds worksheets, dated or selected word lists, or trimmed or marked-up
   copies, **Then** the steps say to flag them as likely derivatives and ask
   the user.
2. **Given** the schema template and the four vault schemas, **When** an
   agent reads "Raw evidence", **Then** it states that raw holds original
   sources only and that AI-made derivatives are not raw evidence.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: The 43 revisions listed in [removals.md](removals.md) MUST be
  removed from the work vault's `raw/`, and no other revision.
- **FR-002**: A worker other than the one that removes them MUST check the
  list against CHE-59's categories before the removal; a bag not clearly in
  the list stays.
- **FR-003**: The work vault's `wiki/log.md` MUST get one entry for the
  removal with the date, the count, the user's decision and the categories,
  and no student names.
- **FR-004**: No Wiki page MAY cite or link a removed file or a file in the
  trashed worksheet folders; each such citation MUST point at the original
  the file came from, or be dropped when raw holds no original.
- **FR-005**: `wiki-consistency check --wiki work` MUST report no findings
  apart from CHE-58's.
- **FR-006**: The `wiki-raw-import` skill's survey and file-list steps MUST
  flag likely derivatives and ask the user; the schema template and the four
  vault schemas MUST state that raw holds original sources only.
- **FR-007**: The rule MUST stay a short judgment rule. The raw-import tool
  MUST NOT gain a classifier or a delete command.

### Key Entities

- **Derivative**: a file generated from original sources, such as a
  worksheet, a dated or selected word list, or a trimmed or marked-up copy.
- **Original source**: a file the user or a publisher, school or provider
  made, such as a catalog, a textbook, an exam paper or an official document.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 0 of the 43 listed bags remain in the work vault; the other
  150 bags remain and pass `verify`.
- **SC-002**: 0 page citations or links point at removed files.
- **SC-003**: `check --wiki work` reports 0 findings outside CHE-58's.
- **SC-004**: The rule appears in the skill's steps 1 and 4, the template
  and all four vault schemas.

## Assumptions

- The removal is a one-time operation done by hand; the raw-import tool
  gains no delete command.
- CHE-58's findings (phone, date and English) stay; the `develop` session
  confirmed on 2026-09-30 that they are outside this feature's check target.
- The vault schemas get only this rule. Their other lag behind the template
  (the sessions line and the backfire tool name) is assigned to CHE-47's
  stage 2.
- The user asked for source paths in [removals.md](removals.md), so it names
  files, against the raw-import skill's default of counts only; it holds no
  student names.
- The CHE-57 feature (concept profiles) commits in the same vault; this
  feature commits there only after CHE-57's vault commit.
