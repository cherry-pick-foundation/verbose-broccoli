# Chat area

Target web chat applications: ChatGPT on the web first, claude.ai on the web
later. Desktop applications are outside this scope unless the user asks for them.

Before designing a custom-server build, check what the web client and the user's
actual account support. An earlier account blocker does not establish current
access or a permanent product limit. Recheck client capabilities before choosing
a transport or reopening a route in the
[chat decision record](../../.specify/assessments/backfire-chat/decision.md).
