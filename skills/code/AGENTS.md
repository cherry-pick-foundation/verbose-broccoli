# Code area

## Model-choice judgments

Choose within the user's session roles and native Orca launch limits. Give
jev-mcp task facts, the task's difficulty and each eligible candidate's
live catalog and remaining usage. Probabilities do not prove correctness.

Model-choice judgments use Jev-family models only. Check the answer's provider
and model. If no Jev route is usable, ask the user through the coordinator;
never fall back to a general model. Follow
[the model-choice procedure](model-choice/references/model-choice.md).

Never include student data, other personal records or credentials in these
judgments.

## Judgment routes

For general judgments, prefer a maker's free API when it fits the
task. Test official subscription command-line routes only when a free API is
uncertain, using existing adapter support. Never call an internal service
endpoint with a command line's sign-in token.

Google models may be used only through Antigravity; do not measure Gemini through
its own API or key. Free substitute models for general judgments do not bypass
the Jev-only model-choice rule. A dated measurement is evidence for that run,
not a permanent availability claim.
